# Pokémon Web Application – 2. semester eksamensprojekt

Dette repository indeholder Gruppens 2. semester eksamensprojekt på datamatikeruddannelsen. Projektet er en webapplikation bygget med C#, Razor Pages, Entity Framework Core og MS SQL Server.

Formålet med projektet var at udvikle en databasebaseret webapplikation med brugerhåndtering, dynamisk indhold og CRUD-funktionalitet.

## Teknologier

* C#
* .NET / Razor Pages
* Entity Framework Core
* MS SQL Server
* LINQ
* HTML
* CSS
* JavaScript
* Git
* Unit testing

## Funktioner

* Visning og håndtering af Pokémon-data
* Moves og relaterede data
* Events
* Brugerregistrering og login
* Session-baseret brugerhåndtering
* CRUD-funktionalitet
* Databaseintegration med Entity Framework Core
* Unit testing af udvalgte dele af projektet

## Hvad vi arbejdede med

I projektet arbejdede vi blandt andet med:

* Objektorienteret programmering i C#
* Razor Pages og opbygning af webapplikation
* Entity Framework Core og databaseforbindelse
* SQL Server og datamodellering
* LINQ og datahåndtering
* Login/session og brugerhåndtering
* Strukturering af kode
* Unit testing og fejlsøgning

## Projektets relevans

Projektet viser vores praktiske fundament inden for C#/.NET, SQL, webudvikling og softwarestrukturering. Det er særligt relevant for studiejob inden for junior .NET/C#, SQL/database, QA/test, IT-support og webudvikling.
